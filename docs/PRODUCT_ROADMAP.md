# 产品路线

## 最终目标

建设汽车底盘竞品数据平台，结合自动数据采集、数据维护员导入维护、AI Agent 调研分析、可视化和 AI 提案能力。

## 阶段一：数据平台基础

目标：先把数据可建、可查、可维护。

- 元数据管理
- 整车/系统/零部件结构树
- 动态字段表单
- 批量导入导出基础
- 权限管理骨架
- 数据可视化基础页面

## 阶段二：数据采集与导入

目标：形成数据进入平台的闭环。

- 汽车之家等公开来源采集任务
- Excel/CSV 导入
- 字段映射
- 导入校验
- 错误行修正
- 数据来源和可信度记录

## 阶段三：AI Agent 分析

目标：输入调研需求，结合平台数据和线上搜索，输出分析报告。

- Agent 需求解析
- 平台数据检索工具
- 在线搜索工具
- 报告生成工具
- 证据链和引用
- 报告版本管理

## 阶段四：可视化与 AI 提案

目标：面向产品/研发/竞品分析场景输出结论和方案。

- 参数对比图
- 零部件材料/重量/尺寸分布
- 车型对比看板
- AI 生成优化建议
- 提案报告导出
