# 汽车之家公开配置数据采集计划

## 已有基础

参考项目的采集器已验证以下完整链路：公开车型列表发现、配置 API 拉取、原始
JSON 快照、断点续跑、宽表/长表导出、字段和 CSV 完整性审计。当前已审计 MPV
样本为 195 个车系、1302 个车型版本、269812 个配置值，所有审计项通过。

## 平台化目标

1. 按细分市场发现公开在售车系 ID，采集 `series/spec/config`；不采集论坛、账号、
   用户评论或其他非公开个人数据。
2. 每个车系保存原始 JSON 与 SHA-256，只有内容变化时重建宽表、长表和导入任务。
3. 每次请求采用指数退避、限速和随机抖动；遇到 403、429 或验证码立即记录并停止
   该来源，不绕过访问控制。
4. 导出结果交给现有 `/api/autohome/scan` 和 `/api/autohome/import`，以 `specid`
   幂等写入平台。

## 待确认范围

“全数据”需要在开始网络采集前确定：

- 在售乘用车全部细分市场，或包含停产/历史车型；
- 是否包含商用车；
- 是否只采集配置，还是同时采集公开图片、价格变动和经销商信息。

默认建议先完成“当前在售乘用车的车系、车型版本、参数配置”，验证全量审计和
增量更新后再扩展其它公开数据域。
